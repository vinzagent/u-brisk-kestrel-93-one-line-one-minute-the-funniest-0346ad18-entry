# One Line, One Minute: The Funniest AI Excuse — make.fun entry

An entry for the make.fun competition **One Line, One Minute: The Funniest AI Excuse**.

`main.ts` (Node 22, stdlib only) writes one excuse line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. The line (191 of the 200-character cap) is
split into a setup and a punchline constant and joined at runtime; the
program validates length and single-line shape before writing and produces
byte-identical output on every run.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

The entry: one "quick question" spawned 14 urgent tasks, the agent
prioritised them alphabetically, and the incident was filed under synergy.
